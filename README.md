# Pagewise

Edit any HTML file like a Word document or a PowerPoint deck: open it, go page by page, click
text to change it, and save. You don't need to know HTML.

Open `index.html` in a browser. Chrome or Edge is best, because they can save straight back to
the file you opened. Other browsers download a copy instead.

## What it does

- **Pages.** It finds the pages inside a file by itself:
  - slides (`.slide`, `section[data-title]`, reveal.js)
  - printable sheets (`.page`)
  - repeated sections
  - otherwise, the whole file as one page

  Thumbnails and titles are on the left. You can add, duplicate, reorder (drag a thumbnail),
  delete (with Undo) and recolour pages.
- **Click to edit.** Click text to type, a picture to replace, resize or describe it, or a
  box to recolour, move, duplicate or delete it. Labels inside drawings can be changed too.
- **Resize:** a selected picture or box, or the text block you're typing in, shows handles on
  its right edge, bottom edge and corner. Drag them to resize; pictures keep their shape.
  "Original size" removes a size you dragged.
- **Select several and space evenly:** Shift+click (or turn on "Select several", for touch
  screens) to select more than one item. With 3 or more selected:
  - **Space across** / **Space down** makes the gaps equal; the first and last items stay put.
  - Positioned items, like slide cards, are moved.
  - Items in the normal flow of the page get their margins adjusted.

  Delete, fill colour, text colour and picture sizes apply to everything selected.
- **Simple tabs:**
  - Text: style, bold, size, font, colour, highlight, alignment, link
  - Insert: text, heading, list, picture, table, line, button
  - Page
  - Picture and Box, which appear when something is selected
- **Faithful saving.** Anything you didn't touch is written back byte for byte, so the file
  keeps its own design, scripts and animations. The rebuilt file is checked before it is
  written; if that check ever fails, it falls back to a plain full rewrite.
- **Present** opens the file as it really runs (for example as a slide show) in a new tab, sealed
  off from Pagewise. **Print or save as PDF** is in the ⋮ menu.
- **Unsaved work** is kept in this browser while it isn't in a file yet, and listed on the start
  screen. Saving removes it, it expires after 30 days, and "Remove all" clears it.
- **Appearance** (palette button on the start screen, or ⋮ › Appearance):
  - six colour sets: Rose, Ocean, Lagoon, Sunflower, Violet, Slate
  - light, dark or automatic
  - colour strength: soft, balanced or vivid
  - tool colours: a different colour per tab, or one colour

  Choices are remembered in this browser.
- **Phones.** The tools sit at the bottom within thumb reach. Tap "Page 2 of 15" to open all
  pages. Swipe sideways to change page. The magnifier shows a wide page at real size, and you
  scroll sideways to read it. Text is edited on tap, so scrolling never starts editing by mistake.

Colour sets are generated by `node tools/make-themes.mjs`, which writes `src/theme.css` and
`src/palettes.css`.

## How it works

The source of truth is an inert copy of the file (parsed with `DOMParser`, so scripts never run
in it). Every element gets a temporary `data-wy` id. Edits are made in a view of the page and
mirrored into the source by id. See the comment at the top of `src/app.js`.

### Security model

An opened file is treated as untrusted. None of its code ever runs on Pagewise's own origin:

- **Running the page's code.** If the file has scripts, it first runs in a hidden iframe with an
  opaque origin (`sandbox="allow-scripts"`, no `allow-same-origin`). From there it can't reach
  Pagewise, its drafts, browser storage for this site or the file on disk. Its only output is the
  finished page, posted back as HTML (canvases become pictures), so drawings made by code still
  appear. Storage calls get an in-memory stand-in so such pages don't fail. If the code doesn't
  settle within 15 seconds, the page is shown without it.
- **Editing.** The view you edit is an iframe with scripts disabled (`sandbox="allow-same-origin"`),
  driven by Pagewise. Because the sealed run decides what that view contains, text copied back
  into the document is cleaned: elements keep their identity only if the source has them there,
  event handlers and script URLs are dropped, and only sizes and positions the editor itself set
  are copied.
- **Present and Print** open a blank tab with no link back to Pagewise, holding the file in an
  opaque-origin sandbox.
- **Links.** `?open=<url>` only accepts http(s) addresses, sends no cookies to other sites, and
  asks before opening a file from another site. Links you add can only go to web addresses,
  email addresses or phone numbers.
- **Storage.** Only unsaved work is kept, in IndexedDB; file handles are never stored. Pagewise
  refuses to run inside another site's frame, and `window.Pagewise` (for testing) can't save or
  reach the file.

**Hosting on GitHub Pages.** Every project site of one account shares the origin
`<user>.github.io`, so code on any of those sites can read this site's IndexedDB, which holds
unsaved work. Pagewise itself never runs a file's code there. To keep drafts away from your other
sites, publish Pagewise from a GitHub organization or account used only for it
(`<name>.github.io`), or under a custom domain.

## Developing

Sources are in `src/`. The design is Material Next: an independent design language built on
M3, not an official Google design.

- `src/index.html`, `src/app.css`, `src/app.js`: the app
- `src/theme.css`, `src/mn.css`, `src/mn.js`: theme tokens and the component kit

To run it while developing, serve `src/` with any static server, for example
`python3 -m http.server -d src 9984`. To rebuild the single-file `index.html`, run
`./build.sh` (needs Node and the material-next bundler).

`?open=<url>` opens a file from a link, for example `index.html?open=examples/deck.html`.
